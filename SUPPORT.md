# Support

## How to file issues and get help

This project uses [GitHub Issues](https://github.com/microsoft/Sparrow-Model-Zoo-Uploader/issues)
to track bugs and feature requests. Please search the existing issues before filing a new one to
avoid duplicates.

When reporting a problem with a conversion or a failed check, include:

- the output of `sparrow-uploader doctor`;
- the command you ran and its JSON output;
- the relevant `.sparrow-upload/<model_id>/evidence/<stage>.json` file.

Do not attach model weights you are not allowed to share, or your parity images.

Problems with the engine itself (a model the engine cannot run, an `spe` crash) belong in the
[Sparrow Engine issues](https://github.com/microsoft/SPARROW-Engine/issues).

## Microsoft Support Policy

Support for this project is limited to the resources listed above.
